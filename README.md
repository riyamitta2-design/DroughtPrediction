# Rain fall prediction project 
## Overview
This project uses machine learning algorithm to predict rainfall based on weather data collected from different districts of India 
The goal of this project is to learn the complete machine learning pipeline which includes:
- Data pre-processing(includes checking missing data types and dropping unwanted columns)
- Exploratory data analysis
- Feature engineering
- Model training
- Model evaluation
## Models 
In this project, we explored three machine learning algorithms:
- Linear regression
- Decision tree regressor
- Random forest regessor
